# SOLEN — Autonomous Geospatial Intelligence API

High-performance sovereign remote sensing and computer vision backend for SOLEN (`https://www.solenn.tech`).

- **Framework**: FastAPI (Python 3.11)
- **Computer Vision**: YOLOv8n-OBB Arbitrary-Angle Oriented Bounding Boxes
- **Geospatial Engine**: GDAL + Rasterio + Shapely
- **Reasoning**: Groq LPU Vision-Language Engine
